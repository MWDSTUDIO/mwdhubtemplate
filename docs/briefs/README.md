## Consignes transverses données en conversation, hors briefs

- Le client n'a **jamais** accès aux agents IA de la maison, ni au dépôt
  de document côté budget. Côté client, la transmission passe par la
  page Documents. La Client view montre exactement ce que voit le couple.
- Un commit et une validation d'Estelle par bloc ; migrations écrites
  par Claude Code, exécutées par Estelle, jamais l'inverse.
- Backlog après les briefs : Resend ou Gmail API, puis Google Meet/Drive.
